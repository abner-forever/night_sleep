## 2026-10-16 判定换成 YAMNet（v3.37）

**目标：** 鼾声 / 梦话自动判定从「一组写死的声学阈值」换成 **YAMNet**——前者在 47 段人工标注上
**覆盖 2% / 准确 0%**，拆掉时长门槛也救不回来。

**关键决策：**
- **统计量用整段均分**，不用最高分。上面那些把阈值定到 0.40 的数字**全是拿均分量出来的**；
  换成最高分等于把「实测支持的结论」换成「看起来更聪明的猜测」。代价是**均分的盲区继承下来了**
  （一段 11.8 秒里只有 3.5 秒是鼾声会被摊薄成弃权）——依据串里多摆一个最高分让它可见。
- **不产出事件区间。** 模型按整段给结论；片级标签训出来的模型定位差，画一对秒数就是画没量过的东西。
- **判定规则单独成一层**（`clip_yamnet.dart`），不 import `tflite_flutter`、不碰 `dart:io`——
  模型在 `flutter test` 里加载不了，规则不拆出来就一条单测都写不了。
- **整批一次 `Isolate.run`**：一段一个 isolate 对手写特征无所谓，对 4 MB 的模型就是白付几十次。
  代价是撞车时两份模型，所以加了串行化。
- **加 v7 → v8 迁移**（全仓唯一一条改数据的迁移）：把旧引擎的判断清回 `pending`。
  不做的话补跑只捡 `pending`，**那 3 段真鼾声会永远停在「待标注」**。
- **旧引擎整条删掉**（`classifyClip` / `detectEvents` / `ClipEvent` / 十条阈值），
  但 `measureClip` / `AudioFeatures` 留着当纯测量。失败记录一个字没删——它是换引擎的理由。

**落地：** `lib/features/sleep/domain/clip_yamnet.dart`（新）、`data/yamnet_scorer.dart`（新）、
`data/clip_analyzer.dart`（批处理重写）、`core/database/app_database.dart`（v8）、
`integration_test/yamnet_eval_test.dart`（新，端侧测量）、
`docs/superpowers/specs/2026-10-16-snore-detection-approaches-design.md` §八（决策记录）。

**新增依赖：** `tflite_flutter: ^0.12.1`（Apache-2.0）；`assets/model/yamnet.tflite`
（4,126,810 B，**进仓库也进包**——它的**许可证未落实，是发布阻塞项**）。

## 2026-10-14 片段自动分析 + Android 整夜录音（v3.26–v3.29）

**目标：** 让机器自己把录到的声音判成「疑似打鼾 / 疑似人声 / 弃权」，不再逐段听逐段标；
并让 Android 上**整夜真的录得到**——否则自动分析只有开录前后那几十秒的原料。

**关键决策：** 自写 FFT，**不引依赖**；滑动窗找「持续够长」的频谱事件，**判不出来就弃权**。
v3.29 拆掉「杂音」兜底：报杂音等于同时断言「不是鼾声」与「不是人声」，而机器在 19 段人工标注上
疑似打鼾召回 **0%**，没资格下这个否定结论。

**结果（负面结论也是结论）：** 四条互相独立的技术路线——频谱形状、背景 / 前景分离、时间结构、
起振快慢——**都已量过、全部不成立**。v3.29 实测 **覆盖 5% / 准确率 0%**：机器事实上处于
「要么不说话，要么说错」的状态，**鼾声检测目前等于没有**。

**Android 侧：** 加了前台服务 `NightRecordingService`，但**「它到底挡不挡得住系统静音，真机
未验证」**。复核方式（`tool/eval_clips.dart` 等）见 README「复核自动分析的两个脚本」——
**正确率必须连同覆盖率一起读**。

## 2026-10-15 全部睡眠数据与导出表格预览（v3.31）

**目标：** 两件使用方提的事——导出页在按下导出之前能**逐格看到**将写进 CSV 的内容；
统计页右上角多一个入口，进二级页按**周 / 月 / 年**翻全部记录。原型两页都没有（它是纯前端
演示、数据不落地），所以按偏差 #18 那一类处理（#66 / #67）。

**关键决策：**

1. **预览与文件同源。** 把「表」抽成第一类对象 `ExportTable` + `SleepExporter.tables()`，
   `csv()` 改成它的**序列化**，界面读同一个 `tables()`。若改成「照 CSV 规则再渲染一遍」，
   就等于把格式知识抄成两份，早晚分叉成一个说谎的预览。顺带把导出排序变成**全序**
   （同一入睡时刻按 id 兜底）：预览与文件是两次独立的排序调用，未定义就等于允许不一致。
2. **只列不画图。** 「全部数据」页不重复统计页的图表与评分卡，只做翻阅；分组口径落在纯函数
   `sleep_history.dart`（按醒来本地日、周一起算、用 `DateTime(y, m, d - n)` 构造而不是
   `subtract(Duration)`）。
3. **预览截断到 50 行并写出来**；**不做 JSON 预览**（嵌套存档铺成表格是给它编一个它并不具有的形状）。

**代价：** 50 行的上限是拍的，不是测出来的；两个新页**没有目视核对**，真机手势手感与大库滚动
性能都没量过（见[验证记录](../../verification-log.md) v3.31）。
