在 `test/schema_migration_test.dart` 末尾追加一个 `_V2Database` 夹具类与新的 `group`。夹具必须**停在 v2**，
且**故意让 `insights` 没有外键**——那正是要迁移掉的旧形态：

```dart
/// 与 `_V1Database` 同构：复用 `app_database.g.dart`，只把版本钉在 v2、
/// 用裸 DDL 建出 v2 的表结构。`insights.record_id` 是 `TEXT NULL`、**不带**
/// `REFERENCES`——这就是要迁移掉的旧形态，也是孤儿行能被留下的原因。
class _V2Database extends AppDatabase {
  _V2Database(super.executor);

  @override
  int get schemaVersion => 2;

  @override
  MigrationStrategy get migration => MigrationStrategy(
        onCreate: (m) async {
          await customStatement('''CREATE TABLE sleep_records (…)''');
          // 其余四张表同形：sleep_stage_segments / sound_clips / insights / app_settings
        },
      );
}
```

五张表的列名、NOT NULL 与 DEFAULT **从真实 v2 库的 `sqlite_master` 里读出来写死**
（`sqlite3 <库> "select sql from sqlite_master …"`），不凭记忆。另加一条**防空跑自检**（与既有的
「夹具必须停在 v2」并列、同一维度）：断言夹具的 `insights` 建表语句**不含 `REFERENCES`**——
否则「外键在迁移后的表上确实存在」那条会**空跑通过**（夹具本来就有），而孤儿行插入也不会报错
（夹具没有 `beforeOpen`，`PRAGMA foreign_keys` 保持 SQLite 默认的 OFF）。

新增用例（放在 `main()` 内的新 `group('v2 → v3', ...)`）：

```dart
            // Rebuild `insights` with the foreign key it should always have had.
            // The orphan sweep has to come first: `alterTable` copies existing
            // rows into the new table, and the pragma that would reject them is
            // off during migration (`beforeOpen` turns it on afterwards, and
            // SQLite never re-validates rows that already exist). Without this
            // the rebuilt table would claim a constraint its contents violate.
            //
            // It also repairs databases already damaged in the field: an app
            // that had demo data cleared carries `demo-N-insight` rows whose
            // records are gone, and re-seeding them is a primary-key clash that
            // throws out of `main()` before `runApp`.
            await customStatement(
              'DELETE FROM insights WHERE record_id IS NOT NULL '
              'AND record_id NOT IN (SELECT id FROM sleep_records)',
            );
            await m.alterTable(TableMigration(insights));
          }
```

```dart
      _busy = true;
      _error = null;
    });
    try {
      await ref.read(sleepRepositoryProvider).installDemoData();
      if (!mounted) return;
      ref.read(toastProvider.notifier).show('演示数据已安装。');

      // 失败必须看得见。此前异常直接逃出去，界面只会表现为「点了没反应」。

    }
```

> **为什么先做一次提取**：`SvgPicture.string` 不暴露它拿到的 SVG 文本
> （`SvgStringLoader` 的字符串是私有字段，公开的 `provideSvg()` 标了 `@protected`，

> 所以染色这件事没法从 widget 树里断言。**把拼 SVG 的那段抽成纯函数**，就能逐字节断言了

先把 `glyph` 里拼字符串的部分抽出为 `AppIcons.svgFor`（**纯函数，无 Widget、无 IO**）：

```dart
  /// The SVG document `glyph` hands to `flutter_svg`, as a plain string.
  ///
  /// Split out so the colour substitution can be asserted directly. Reading it
  /// back off the widget tree is not possible: `SvgStringLoader` keeps the string
  /// private and its `provideSvg` is `@protected`.
  static String svgFor(
    String body, {
    required Color color,
    double strokeWidth = 1.6,
  }) {
    final paint = _hex(color);
    final resolved = body.replaceAll('currentColor', paint);
    return '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" '
        'fill="none" stroke="$paint" stroke-width="$strokeWidth" '
        'stroke-linecap="round" stroke-linejoin="round">$resolved</svg>';
  }
```

```dart
  static Widget glyph(
    String body, {
    double size = 24,
    Color? color,
    double strokeWidth = 1.6,
    String? semanticLabel,
  }) {
    // No silent fallback. A missing `color` used to paint #000000 — invisible on
    // a dark background, and the reason the record page's event icons were black
    // in dark mode. All 97 call sites pass one; fail loudly on the next omission.
    assert(color != null, 'AppIcons 必须显式传 color：漏传会画成黑色');
    final svg = svgFor(
      body,
      color: color ?? const Color(0xFF000000),
      strokeWidth: strokeWidth,
    );

    return SvgPicture.string(
      svg,
      width: size,
      height: size,
      // Exclude from semantics by default; callers that need a label wrap the
      // icon in a labelled control, matching the prototype's aria handling.
      excludeFromSemantics: semanticLabel == null,
      semanticsLabel: semanticLabel,
    );
  }
```
