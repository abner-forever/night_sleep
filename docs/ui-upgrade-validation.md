## 保持的业务边界与设计差异

- 没有修改数据库结构 / 迁移、Riverpod、GoRouter 方案、服务层或音频领域判定。会话 `CustomTransitionPage` 保留 `state.pageKey`。
- 没有阶段、评分、波形、录音文件、AI 配置或余额时如实展示缺失；不复制原型中的示例测量值、时间轴或转写文本。
- 音效仍是工程已有的五种；场景仍是八种。普通音效弹层关闭停止，会话音效面板收起继续播放，两种所有权没有合并。
- 统计周期保留原有按记录取样的口径；没有擅自改为日历窗口。首页平均时长明确写「最近 7 条平均时长」。
- 原生破坏性确认和传统罗盘盘面保留；通过新版外壳与语义色统一。
- 权限仍在启用功能时申请；录音失败、平台静音与后台能力不以 UI 替代实际状态。
